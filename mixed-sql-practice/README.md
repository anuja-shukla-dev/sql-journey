# SQL Mixed Practice

This folder contains daily SQL practice sessions designed to strengthen concepts covered during my 18-day SQL learning journey.

Instead of immediately moving on to new topics, I am focusing on improving my problem-solving skills through mixed SQL queries using my `topper_sql` database.

## Objectives

- Strengthen SQL fundamentals and advanced concepts.
- Improve query-writing skills and logical thinking.
- Practise combining multiple SQL concepts.
- Understand joins, subqueries, aggregate functions, and other SQL operations.
- Develop confidence in solving real-world database problems.

## Practice Structure

- 5 mixed SQL questions every day.
- Gradually increasing difficulty.
- Independent query writing before checking solutions.
- Regular revision of previously covered concepts.
- Focus on query accuracy, logic, and efficiency.

## Day-wise Progress

| Day | Topics Covered | Questions |
|---|---|---:|
| Day 01 | Joins, Aggregation, GROUP BY, HAVING, Subqueries, DISTINCT | 5 |
| Day 02 | INNER JOIN, Multiple JOIN Conditions, COUNT, DISTINCT, IN, AVG, GROUP BY, HAVING | 5 |

## Day 01 – Topics Practised

1. Student performance analysis using JOIN and aggregate functions.
2. Finding students without course enrollments using LEFT JOIN and IS NULL.
3. Course-wise enrollment statistics and average marks.
4. Finding above-average performers using scalar subqueries.
5. Teacher-wise enrollment reports using multiple LEFT JOINs and COUNT(DISTINCT).

## Day 02 – Topics Practised

1. Filtering students based on age using WHERE and ORDER BY.
2. Calculating course-wise enrollment counts using JOIN and GROUP BY.
3. Finding students scoring above 80 using multiple JOIN conditions and DISTINCT.
4. Filtering teachers by subjects using the IN operator.
5. Identifying students with average marks above 75 using AVG, GROUP BY, and HAVING.

## Database Used

`topper_sql` – Student Performance Management System.

## Goal

My goal is to move beyond memorising SQL syntax and develop the ability to independently analyse database problems, understand relationships between tables, and write accurate and efficient queries.

**Consistency over memorisation. Practice over shortcuts.**
