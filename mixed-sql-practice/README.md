# SQL Mixed Practice

This folder contains daily SQL practice sessions designed to strengthen concepts covered during my 18-day SQL learning journey.

Instead of immediately moving to new topics, I am focusing on improving my problem-solving skills through mixed SQL queries using my `topper_sql` database.

## Objectives

- Strengthen SQL fundamentals and advanced concepts.
- Improve query-writing and logical thinking.
- Practise combining multiple SQL concepts.
- Understand joins, subqueries, and aggregate functions.
- Develop confidence in solving real-world database problems.

## Practice Structure

- 5 mixed SQL questions per day.
- Gradually increasing difficulty.
- Independent query writing before checking solutions.
- Regular revision of previously covered concepts.
