# Day 13 — SQL Views

## Topic

**Views in MySQL**

## What I Learned

* What a View is and why it is used.
* Creating Views using `CREATE VIEW`.
* Retrieving data from Views using `SELECT`.
* Using Views with `WHERE` conditions.
* Creating Views using `JOIN`.
* Using a View as a source for another query.
* Using `CREATE OR REPLACE VIEW` to modify an existing View.
* Removing Views using `DROP VIEW`.
* Got a small introduction to using a **subquery with a View**.

## Practice

Created and worked with Views for:

* Basic student information
* Passing students
* Course information
* High scorers
* Adult students
* Student-course details
* Student marks report

Also practiced:

* Filtering data from Views
* Finding the highest marks using a subquery
* Modifying an existing View
* Dropping a View

## Key Learning

A View does not store a separate copy of the data. It stores a query definition and presents its result like a table.

The most valuable part of today's practice was working through queries that initially felt difficult instead of abandoning them. I had to think about table relationships, joins, aggregate functions, and subqueries.
