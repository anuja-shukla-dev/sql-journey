### Day 16 — GROUP BY & HAVING

**Topics Covered:**

* `GROUP BY`
* Grouping data using single and multiple columns
* Aggregate functions with `GROUP BY`
* `HAVING`
* Difference between `WHERE` and `HAVING`
* Combining `WHERE`, `GROUP BY`, and `HAVING`
* `COUNT()`, `AVG()`, `MAX()`, `MIN()`, and `SUM()` with grouped data

**Practice:**

* Wrote 19 SQL queries using the Student Performance Management System database.
* Practiced grouping students and courses using aggregate functions.
* Used `HAVING` to filter grouped results.
* Combined `WHERE`, `GROUP BY`, and `HAVING` in project-based queries.

**Key Learning:**

* `GROUP BY` groups rows with the same values so aggregate functions can be applied to each group.
* `WHERE` filters individual rows before grouping.
* `HAVING` filters groups after aggregation.
