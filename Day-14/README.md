### Day 14 — Indexes

Learned about **Indexes** in MySQL and how they improve the speed of data retrieval.

Topics covered:

* Creating indexes using `CREATE INDEX`
* Viewing indexes using `SHOW INDEXES`
* Dropping indexes using `DROP INDEX`
* Creating composite indexes on multiple columns
* Understanding the advantages and trade-offs of indexes
* Understanding why indexes should be created selectively

Practiced creating and managing indexes using the `students` table from my `topper_sql` database.
