# SQL Day 10 – UNION & UNION ALL

## Topics Covered

* UNION
* UNION ALL
* Removing duplicate rows
* Preserving duplicate rows
* Combining results from multiple tables
* Using WHERE with UNION
* Using ORDER BY with UNION
* Adding a fixed column while combining results
* Using UNION ALL with a subquery and COUNT()

## Practice

Created `current_students` and `alumni` tables and practiced combining their data using `UNION` and `UNION ALL`.

## Key Learning

* `UNION` combines result sets and removes duplicates.
* `UNION ALL` combines result sets while keeping duplicates.
* Queries combined with UNION must return the same number of columns with compatible data types.
* `ORDER BY` can be used to sort the final combined result.
* UNION can be combined with other SQL concepts such as filtering, subqueries, and aggregate functions.
